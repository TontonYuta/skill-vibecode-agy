## 📖 Giới thiệu (Overview)

Vibecoding không đơn thuần là gõ prompt để AI viết mã. **Smart Vibecoding** là nghệ thuật trao quyền tự chủ tuyệt đối (**Zero-Touch Autonomy**) cho AI Coding Agents, kết hợp hệ thống rào chắn kiểm thử tự động (**Loop-Until-Green TDD**), kỹ thuật bảo tồn ngữ cảnh (**Token Frugality**) và phân phối đa tác tử (**Multi-Agent Swarm**).

Repository này tập hợp:
1. **14 bộ Skills chuyên sâu**: Chuẩn hóa từ thiết kế hệ thống, tối ưu token, sửa lỗi gốc rễ, UI/UX hiện đại đến sản xuất video hoạt họa toán học Manim CE 9:16 Shorts/TikTok và tự động hóa tài liệu LaTeX đa môn học.
2. **Quy chuẩn Agent Rules (`AGENTS.md`)**: Bộ chỉ thị bất biến giúp Agent tự sửa lỗi, tự build, tự test và hoàn thiện từ A-Z mà không làm phiền người dùng.
3. **Playbooks & Case Studies thực chiến**: Đúc kết từ các dự án thực tế như ứng dụng học tiếng Anh Zero-API (`english-no-api`), hệ sinh thái video Manim CE, và hệ thống đề thi LaTeX TikZ.

## 🏛️ 4 Trụ Cột Triết Lý Vibecoding

### 1. Toàn Quyền Tự Chủ (Zero-Touch Autonomy)
Agent không dừng lại giữa chừng để hỏi những câu thừa thãi như *"Tôi có nên chạy test không?"* hay *"Tôi có thể sửa file này không?"*. Agent nhận mục tiêu, tự lập kế hoạch nguyên tử, thi công code, tự sửa lỗi phát sinh và hoàn tất từ đầu đến cuối.

### 2. Bắt Buộc Kiểm Thử (Loop-Until-Green)
Không có tính năng nào được coi là xong nếu test suite chưa chạy và đạt **100% Pass**. Mọi bugfix đều phải đi kèm unit test phòng chống hồi quy (regression prevention).

### 3. Tiết Kiệm Ngữ Cảnh (Token Frugality)
- Sử dụng `grep_search` để định vị số dòng, sau đó chỉ đọc lát cắt 30–80 dòng bằng `view_file`.
- Thay đổi code bằng `replace_file_content` thay vì viết đè toàn bộ tệp nguồn.
- Lọc output terminal qua `head -n 40` để ngăn context window bị tràn rác.

### 4. Phân Vai Đa Tác Tử (Multi-Agent Delegation)
Tách bạch ranh giới trách nhiệm: **Spec Architect** (lập thiết kế & contracts), **Fast Researcher** (tra cứu siêu tốc với model `flash`), **Code Implementer** (thi công chính xác), **Code Auditor** (rà soát bảo mật), và **QA Tester** (chạy test độc lập).

## 🚀 Cài Đặt & Sử Dụng Nhanh

### Cách 1: Cài đặt tự động 1-Click (Khuyên dùng)
Clone repository và chạy script cài đặt:
```bash
git clone https://github.com/TontonYuta/skill-vibecode-agy.git
cd skill-vibecode-agy

# Cài đặt toàn bộ skills & rules vào Antigravity toàn cục (~/.gemini/config/)
./scripts/install-skills.sh

# Hoặc cài đặt dạng symlink (tự động cập nhật khi pull repo):
./scripts/install-skills.sh --symlink

# Hoặc cài đặt cục bộ cho một dự án cụ thể (.agents/skills):
./scripts/install-skills.sh --local
```

### Cách 2: Cài đặt thủ công
Copy các thư mục bên trong `skills/` vào đường dẫn cấu hình Antigravity của bạn:
- **Global**: `~/.gemini/config/skills/`
- **Project-level**: `<workspace>/.gemini/skills/` hoặc `<workspace>/.agents/skills/`
- **Rules**: Copy `rules/AGENTS.md` vào thư mục gốc dự án hoặc `~/.gemini/config/rules/AGENTS.md`.

## 📚 Playbooks & Kinh Nghiệm Thực Chiến

Tất cả các case study và phân tích kỹ thuật chuyên sâu được biên soạn trong thư mục [`playbooks/`](playbooks/):

2. 📗 [`02-loop-until-green-tdd.md`](playbooks/02-loop-until-green-tdd.md): Thiết lập harness kiểm thử Node.js siêu tốc (`node:test` + `tsx`) dưới 50ms cho 30+ tests.
3. 📙 [`03-token-frugality-and-context-pruning.md`](playbooks/03-token-frugality-and-context-pruning.md): Kỹ thuật lát cắt tệp (Slice-based) và chống tràn context khi vibecoding nhiều ngày.
4. 📕 [`04-multi-agent-swarm-orchestration.md`](playbooks/04-multi-agent-swarm-orchestration.md): Thư viện prompt phân vai và giao thức Lean Handoff qua con trỏ URI.
5. 🔬 [`05-case-study-english-no-api.md`](playbooks/05-case-study-english-no-api.md):
   - Xây dựng app học tiếng Anh hoàn toàn không tốn tiền API (Edge TTS + Web Speech + Local Phonetic Scoring).
   - Thiết kế thuật toán Leitner Spaced Repetition 5 hộp nhớ.
   - Tính năng **Mobile Remote QR**: Kết nối LAN Wi-Fi và đường hầm **Cloudflare Quick Tunnel** an toàn cho 4G/5G.
   - Post-Mortem xử lý triệt để lỗi minified runtime `i is not iterable` và cấu hình Vite 6 `allowedHosts: true`.
6. 🎬 [`06-case-study-manim-math-animations.md`](playbooks/06-case-study-manim-math-animations.md): Kiến trúc 5 phân cảnh vàng, hàm chống tràn `fit_width`, và tiếp tuyến đổi màu với `always_redraw`.
7. 📑 [`07-case-study-latex-pro-docs.md`](playbooks/07-case-study-latex-pro-docs.md): Tự động hóa sinh đề thi và sơ đồ TikZ chuẩn in ấn A4.
