## 🗺️ Cấu Trúc Phân Bổ 7 Chương Cốt Lõi

1. **Chương 1**: *Khởi nguyên & Bản chất kỹ nghệ Vibecoding* (Nợ nhận thức, Kinh tế học Token, Attention Degradation, Reimplementation Trap).
2. **Chương 2**: *Phân tích nghiệp vụ, Định hình MVP & Khung JTBD* (Jobs-to-be-Done, Quy tắc cắt 50% tính năng, MoSCoW, Socratic Framing /grill-me).
3. **Chương 3**: *Giải phẫu hệ sinh thái Tech Stack: Khả năng & Ranh giới* (Playwright làm được gì & giới hạn là gì, REST vs Server Actions vs FastAPI, Supabase vs SQLite, TypeScript & shadcn/ui).
4. **Chương 4**: *An ninh mã nguồn & Phòng thủ lỗ hổng CWE/OWASP* (Last Secure Code Benchmark 65% lỗi, SQLi, IDOR & RLS, rò rỉ secret key, kiểm toán tự động).
5. **Chương 5**: *Thiết kế kiến trúc logic & Khóa cứng bằng Schema* (Schema-First, Máy trạng thái 4 bước: Idle $\to$ Loading $\to$ Success $\to$ Error/Empty, Micro-modules < 200 dòng, Circuit Breakers).
6. **Chương 6**: *Nguyên lý thiết kế UX/UI chuyên nghiệp: Diệt trừ AI Slop* (Xóa sổ chất nhựa, Hệ màu 60-30-10, Nhịp điệu khoảng trắng 8px, Typography Inter/Geist).
7. **Chương 7**: *Mindful Vibecoding & Hệ điều hành tự chủ* (TECH_STACK.md bắt buộc, 2-Strike Git Reset, Root-Cause Post-Mortem, Zero-Touch Hooks, Loop-Until-Green).
